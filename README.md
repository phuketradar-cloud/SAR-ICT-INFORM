# IT Survey Web App (Direct Open Edition)

## เปิดใช้งาน
1. แตกไฟล์ ZIP ลงในเครื่อง
2. เปิดโฟลเดอร์ `UnitSurveyWebApp`
3. ดับเบิลคลิก `index.html` เพื่อเปิดด้วย Chrome หรือ Edge
4. กด “เพิ่มรายการ” เพื่อเริ่มกรอกข้อมูล

## ความสามารถ
- ข้อมูล 5 หมวดตามแบบฟอร์ม Excel
- เพิ่ม / ดู / แก้ไข / ลบ / ค้นหา
- เก็บข้อมูลใน localStorage ของเบราว์เซอร์
- ส่งออก Excel จากไฟล์ต้นฉบับที่ฝังอยู่ในแอป

## ข้อควรทราบ
- การเพิ่ม/แก้ไข/ลบ/ค้นหา ใช้งานได้เมื่อเปิด index.html โดยตรง
- ปุ่มส่งออก Excel ต้องโหลดไลบรารี ExcelJS จากอินเทอร์เน็ตในครั้งแรก หากไม่มีอินเทอร์เน็ต ปุ่มส่งออกจะยังใช้ไม่ได้
- ข้อมูลถูกเก็บใน browser profile ของเครื่องนี้ อย่าล้างข้อมูลเว็บไซต์/เบราว์เซอร์ และควรส่งออก Excel สำรองเป็นระยะ
- ไฟล์นี้ไม่ได้โฮสต์เป็นเว็บไซต์สาธารณะ และยังไม่ได้ผ่านการทดสอบบนอุปกรณ์ Android จริง
